title: "Aplicaciones"
---

Proyectos y aplicaciones que usan, extienden o documentan la API del Servicio de Normalización de Datos Geográficos.

:::note
Estos proyectos se hicieron para la v1.0. Antes de usarlos con la v2.1, revisá que apunten a `https://apis.datos.gob.ar/georef/api/v2.1/` y que contemplen los [cambios de la v2](/georef-ar-api/migrar-desde-v1/) (por ejemplo, `municipio` pasó a ser `gobierno_local`).
:::

## De terceros

* [pdelboca/georefar](https://github.com/pdelboca/georefar): interfaz en R para usar la API, por [pdelboca (GitHub)](https://github.com/pdelboca).
* [juancarlospaco/nim-georefar](https://github.com/juancarlospaco/nim-georefar): interfaz en Nim para usar la API, por [juancarlospaco (GitHub)](https://github.com/juancarlospaco).

## Del equipo de Datos

* [Taller Georef en IDERA 2023](https://www.youtube.com/watch?v=-7EeGl83xWA): taller del encuentro de capacitación de IDERA 2023, con ejemplos de uso de la API con Google Sheets y Colab.
* [datosgobar/taller-georef-pyconar-2018](https://github.com/datosgobar/taller-georef-pyconar-2018): taller de PyConAr 2018 (Buenos Aires), con ejemplos de uso de la API con Pandas y Jupyter Notebook.
